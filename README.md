# Discord-бот «Сервер под ключ»

Готовый бот для игровых и тематических Discord-серверов. Один файл настроек —
под каждого покупателя разворачивается за 10 минут.

## Что умеет

- 🎫 **Тикеты** — панель с кнопкой, личный канал для каждого обращения, доступ у поддержки
- 👋 **Приветствие** — сообщение новичку в заданный канал + автороль
- 🛡 **Модерация** — kick, ban, мут по таймеру, размут, очистка сообщений
- 💰 **Экономика** — баланс, ежедневная награда, переводы, топ богачей
- 📢 **Объявления** — красивые эмбеды от имени сервера
- 📋 **Логи** — все действия в отдельный канал `логи`

## Установка

1. Discord Developer Portal (discord.com/developers) → New Application → Bot → скопируй токен. Включи **Privileged Intents**: Server Members и Message Content.
2. Впиши токен и настройки в `config.py` (или переменные окружения).
3. Пригласи бота на сервер (OAuth2 → URL Generator → `bot` + права Administrator, или минимум: Manage Channels, Manage Roles, Kick/Ban Members, Timeout, Manage Messages).
4. На сервере создай текстовые каналы `приветствие`, `логи`, категорию `тикеты` и роль `Поддержка` (имена меняются в config.py).

```bash
pip install -r requirements.txt
python bot.py
```

## Команды

`!ticketpanel` — опубликовать панель тикетов (админ)
`!close` — закрыть тикет
`!kick @юзер`, `!ban @юзер`, `!mute @юзер 30`, `!unmute @юзер`, `!clear 20`
`!balance`, `!daily`, `!pay @юзер 100`, `!top`
`!announce текст` — объявление (админ)
